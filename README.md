# Kasane

Mac 用のクリップボード管理アプリです。Raycast / Paste のような検索とプレビューの画面に、Clibor の FIFO / LIFO 連続ペーストを組み合わせています。

名前は日本語の「重ね」からです。半透明のガラスが重なる見た目と、コピーを積み重ねて順に貼る FIFO / LIFO のスタックを表しています。

- macOS 26 以上、Apple Silicon のみ
- 履歴はローカルの SQLite に保存します（同期なし）
- ライセンス: MIT

> 開発中（MVP）です。英語表示はまだありません。見た目は[デザインモック](https://claude.ai/artifact/Ln3dutffPpCU8sWcVu5c1L)の「C案 改訂版」をもとに、実機で微調整する前提です。

## できること

- クリップボードの履歴（テキスト、リッチテキスト、URL、画像、ファイル）を保存
- fzf と同じ考え方のあいまい検索。ローマ字でも日本語の項目にヒット（`kaigi` で「会議」）
- 履歴ウインドウ（動かせて大きさも変えられる）で、キーボードだけで選んで元のアプリに自動ペースト
- ピン留め、並び順の切り替え（コピー日時順 / ペースト回数順）
- FIFO / LIFO モード: コピーした順（または逆順）に、⌘V で 1 件ずつ貼り付け。全部貼り付けると自動で解除
  - モード中は画面の左上か右上の小さいウインドウに、キューの全件を貼り付ける順に表示
  - モード中も履歴ウインドウはいつもの履歴のまま。⌘⏎ で選んだ項目をキューに追加できる
- 設定: メニューバーの「設定…」か、履歴ウインドウで ⌘, を押すと開く。タブは 一般 / 履歴 / 検索 / ショートカット / 外観
  - 外観で、アクセントカラー、背景の不透明度とぼかしの強さ、履歴ウインドウの文字の大きさ（⌘+ / ⌘− でも変わる）、小さいウインドウの位置（左 / 右）と文字の大きさを変えられる
  - 履歴で、保存件数、並び順、URL のタイトルと画像の表示、履歴に残さないアプリを変えられる
- URL のプレビューでページのタイトルと画像を取りに行くかを選べる（初期値はオフ）

## 検索のしかた

fzf と同じ考え方のあいまい検索です。

- 文字が順番どおりに含まれていれば、間が空いていても当たる（`gtps` で `git push`）。ただし離れすぎていると当たらない。どこまで離れてよいかは設定の「検索」タブの「検索のゆるさ」で選ぶ
- ローマ字でも日本語の項目に当たる（`kaigi` で「会議」、`tokyo` と `toukyou` で「東京」）。「ん」を `nn` と打っても当たる
- 空白で区切ると、すべての語に当たる項目だけが出る（AND）
- `'` で始めた語は完全一致。文字が続けてそのまま含まれている項目だけが当たる（`'kaigi`）
- 大文字と小文字、全角と半角は区別しない

検索中の並び順:

- 検索欄に文字を入れている間は、よく当たった順に並べ替える。文字が続けて当たる、語の先頭で当たる、などほど上に来る
- 同じくらい当たった項目どうしは、ふだんの並び順（コピー日時順かペースト回数順）のまま
- ピン留めした項目は、検索中も上にまとまる
- 検索欄を空にすると、ふだんの並び順に戻る

## ショートカット（仮）

| キー | 動作 |
| --- | --- |
| ⌥V | 履歴ウインドウを開く / 閉じる |
| ⌥⌘F | FIFO モードの開始 / 終了 |
| ⌥⌘L | LIFO モードの開始 / 終了 |

- Mac 全体で先に受け取るので、他のアプリの同じキーは効かなくなる（例: PhpStorm の ⌥⌘L コードの整形、⌥⌘F フィールドの導入。⌥V で入力する文字「√」）。困るときは下のコマンドで変える

履歴ウインドウの中:

| キー | 動作 |
| --- | --- |
| ↑ ↓ | 選択 |
| ⏎ | 元のアプリに貼り付け |
| ⇧⏎ | 書式なしで貼り付け |
| ⌘⏎ | コピーだけする。FIFO / LIFO 中は、選んだ項目をキューに追加する |
| ⌘1〜⌘9 | 上から n 番目を貼り付け |
| ⌘I | プレビューの下に詳細（種類、コピー元、日時など）を出す / 隠す |
| ⌘P | ピン留め / 解除 |
| ⌘D / ⌘⌫ | 削除 |
| ⌘+ / ⌘− | 一覧とプレビューの文字を一段大きく / 小さく（標準・大・特大。JIS 配列は ⌘; でも大きくなる） |
| Page Up / Page Down | 8 件ずつ選択を動かす |
| Esc | 検索語を消す。空なら閉じる |
| ⌘W | 閉じる |
| ⌘V | 検索欄に貼り付け。改行を含む文字は 1 行にして貼る |
| ⌘C / ⌘X | 検索欄の文字をコピー / 切り取り |
| ⌘A | 検索欄の文字を全部選ぶ |
| ⌘Z | 検索欄の Undo（直前の編集を戻す。続けて打った文字はまとめて戻る） |
| ⇧⌘Z | 検索欄の Redo（Undo で戻した編集をやり直す） |

- 決まり: ⏎ は貼り付け、⇧ を足すと書式なし。それ以外の操作はすべて ⌘ を使う
- 貼り付けた項目は、リストの中で動かない。⌘⏎ でコピーした項目は、⌘C でコピーしたときと同じく一番上に移る

- 開くと日本語入力をオフ（英数）にし、閉じると開く前の入力方法に戻す。ローマ字で日本語の項目も検索できる。日本語で検索したいときは、かなキーで切り替える。切り替えないようにするには、設定の「検索」タブで「開いたときに英数に切り替える」をオフにする
- FIFO / LIFO 中に履歴ウインドウから ⏎ などで貼った項目は、その 1 回だけ貼られ、キューは減らない

ショートカット（⌥V、⌥⌘F、⌥⌘L）は、設定の「ショートカット」タブで変えられます。前の版で `defaults write … hotkey.history` のように変えていた場合は、その設定を引き継ぎます。

## ビルド

必要なもの: Xcode 26 以上（macOS 26 SDK と Swift 6.2）

```sh
git clone https://github.com/kazuya-tanimoto/kasane.git
cd kasane
make test   # ユニットテスト
make run    # build/Kasane.app を作って起動
```

### 権限が外れないようにする（開発時）

ad-hoc 署名だとビルドのたびに署名が変わり、アクセシビリティの許可が外れることがあります。自己署名の証明書で署名すると、ビルドし直しても許可が残ります。

証明書はターミナルだけで作れます。最後に画面に出る確認ダイアログで macOS のパスワードを入力します（ターミナルには入力しません）。

```sh
make dev-cert
make run SIGN_IDENTITY="Kasane Dev"
```

キーチェーンアクセスで作る場合は次のとおりです。

1. 「キーチェーンアクセス」を開き、左側で「ログイン」キーチェーンを選んでから、メニューの「キーチェーンアクセス > 証明書アシスタント > 証明書を作成…」を選ぶ
2. 名前を `Kasane Dev`、固有名の種類を「自己署名ルート」、証明書のタイプを「コード署名」にして作成する
3. 作った証明書をダブルクリックし、「信頼 > コード署名」を「常に信頼」にする
4. `security find-identity -p codesigning` に `"Kasane Dev"` が出ることを確かめる
5. その証明書で署名してビルドする

```sh
make run SIGN_IDENTITY="Kasane Dev"
```

## 初回起動時の権限

| 権限 | 用途 |
| --- | --- |
| 他のアプリからのペースト | クリップボードの履歴を取る |
| アクセシビリティ | 自動ペースト、FIFO / LIFO 中の ⌘V の検知 |

初回起動時に案内の画面が出ます。許可の状態は、設定の「一般」タブで確かめられます。許可が足りないときは、メニューバーに「⚠︎ 許可の設定が必要です…」が出ます。

## 公証なしのアプリを開く

GitHub Releases から入手したアプリは公証していないため、初回起動時に警告が出ます。「システム設定 > プライバシーとセキュリティ」を開き、Kasane の「このまま開く」を選んでください。

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `Sources/KasaneCore` | あいまい検索、文字の正規化、FIFO / LIFO のキュー（OS に依存しない） |
| `Sources/KasaneStore` | 履歴の保存（SQLite / GRDB）。重複の統合、件数の上限、ピン留め |
| `Sources/Kasane` | アプリ本体（AppKit / SwiftUI）。監視、ペースト、ウインドウ、メニューバー |
| `docs/manual-test.md` | 実機での確認項目 |

データは `~/Library/Application Support/Kasane/` に保存します。
