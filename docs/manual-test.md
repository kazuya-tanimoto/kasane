# 実機での確認項目（MVP）

クラウドの開発環境では、Mac 用のビルドと動作確認ができません。Mac で次の順に確認してください。結果は PR かスレッドに書いてもらえれば直します。

このファイルとアプリの画面だけで確認できるように書いています。デザインモックと見比べる必要はありません。

- この版にあるはずの機能は、すべて下の 0〜9 章に書いています。書いてあるとおりに動かなければ不具合です
- 書いていないことでも、使っていておかしいと感じたら知らせてください。ただし、次の「この版にまだないもの」は除きます

## 今回確認してほしい範囲（2026-10-17、FIFO / LIFO と履歴ウインドウの見直し）

仕様の見直し（FIFO / LIFO 中の履歴ウインドウ、小さいウインドウ、日本語入力）を入れた版です。PR #3 の確認は、次の 3 つの章の **チェックが付いていない項目** だけです。

- 3 章 履歴ウインドウと検索（「Kasane」の帯と日本語入力が新しい）
- 4 章 ペースト（⇧⏎ と ⌥⏎ が残り。⌥⏎ の確認方法を詳しくした）
- 5 章 FIFO / LIFO（小さいウインドウと、モード中の履歴ウインドウが新しい）

チェックが付いている項目は、前の版で確認済みで、今回の変更で動きが変わらないものです。PR #2 をマージする前の全体の確認（6〜9 章を含む）は、これとは別に行います。

前回から変わったこと:

- 履歴ウインドウの一番上に「Kasane」の帯ができ、どこをつかんでもウインドウが動く
- 開くと日本語入力がオフ（英数）になり、閉じると開く前の入力方法に戻る
- 検索欄で日本語の変換中の Enter は、変換の確定だけになった（前は貼り付けになっていた）
- FIFO / LIFO 中も、履歴ウインドウはいつもの履歴のまま。前にあった「FIFO 3」のボタン、Tab での切り替え、キューの一覧はなくした
- FIFO / LIFO 中は「コピー ⌥⏎」のボタンが「キューに追加 ⌥⏎」になり、⌥⏎ で選んだ項目をキューに追加する
- 小さいウインドウ（前は「小さな表示」と呼んでいたもの）は、モード中は履歴ウインドウを開いていても出る。キューの全件を出し、件数に合わせて縦に伸びる。画面に収まらないときだけ中をスクロールできる
- 小さいウインドウはクリックを受け止める（下のアプリには通さない）。クリックしても、作業中のアプリに入力したままでいられる

## 仕様どおりの制限（不具合ではない）

- 履歴ウインドウには、FIFO / LIFO を始める・終えるボタンがない。モードの表示もない。始め方と終え方はショートカットか、メニューバーのメニューだけ。モード中かどうかは、メニューバーのアイコンと小さいウインドウで見る
- 小さいウインドウは動かせない。位置はメニューの「見た目 > FIFO / LIFO の小さいウインドウの位置」で四隅から選ぶ
- FIFO / LIFO 中に、メニューの「ペースト」や右クリックから貼り付けたときは検知しない
- PR #2 より前に保存した履歴は、同じものをもう一度コピーすると 1 回だけ別の項目として入る。重複をまとめる計算を変えたため。新しくコピーしたものは正しくまとまる

### 日本語入力（新しい項目）

テキストエディットで新しい書類を開き、日本語入力（ひらがな）にして「てすと」と打てる状態にしてから始めてください。

- [ ] ⌃⌘V で開くと、メニューバーの入力方法の表示が英数（「A」など）に変わる。そのまま `kaigi` と打つと、検索欄に「kaigi」とローマ字のまま入る（「かいぎ」にならない）
  - 「A」に変わったのに、打つと「かいぎ」になる場合は不具合です（入力方法の切り替えがすぐ効かない、という macOS の既知の問題に当たっている可能性があります）。どちらだったか教えてください
- [ ] Esc を 2 回押して閉じると、メニューバーの表示がひらがな（「あ」）に戻り、テキストエディットで打つとひらがなが入る
- [ ] ウインドウを開いてから かなキーを押すと、日本語で入力できる。「かいぎ」と打って Enter を押すと **変換が確定するだけ** で、ウインドウは開いたまま、何も貼り付けられない
- [ ] 確定したあと、もう一度 Enter を押すと、選択中の項目がテキストエディットに貼り付けられる
- [ ] 変換中に ↓ を押すと変換の候補が動き、左のリストの選択は動かない
- [ ] 変換中に Esc を押すと変換が取り消されるだけで、ウインドウは閉じない
- [ ] 日本語に切り替えて閉じたときも、閉じたあとは開く前の入力方法（ひらがな）に戻っている
- [ ] 開く前が英数だったときは、閉じたあとも英数のまま

- [x] 日本語入力（ひらがな）のアプリに貼り付けても問題ない

## 5. FIFO / LIFO（最重要リスク）

要件書で「実機で最優先に検証する」としていた部分です。方式は「⌘V のイベントを貼り付け先に渡す前に、クリップボードを入れ替える」です。

FIFO / LIFO は、ショートカット（⌃⌥⌘F / ⌃⌥⌘L）か、メニューバーのメニューの「FIFO モードを開始」「LIFO モードを開始」で始めます。履歴ウインドウにはボタンがありません。

以下の A、B、C は、テキストエディットに「A」「B」「C」と 1 行ずつ書いておき、1 行ずつ選んで ⌘C でコピーしてください。

### 基本

- [x] ⌃⌥⌘F で FIFO モードになり、メニューバーに「FIFO 0」と出る
- [ ] 始めると同時に画面の右上に小さいウインドウが出て、「FIFO」の札、「残り 0 件」「コピーするとここに追加されます」と出る
- [x] モード中に同じショートカットをもう一度押すと解除される
- [ ] 解除すると小さいウインドウが消える
- [x] メニューバーのメニューの「FIFO モードを開始」でも同じように始まる
- [x] A、B、C の順にコピーすると、メニューバーが「FIFO 3」になる
- [ ] そのとき小さいウインドウに「1 A」「2 B」「3 C」と並ぶ。1 の番号はアクセントカラーの色で、A は太字
- [x] テキストエディットで ⌘V を 3 回押すと A、B、C の順に貼られ、3 回目のあとにモードが自動で解除される
- [ ] ⌘V を押すたびに小さいウインドウの一番上が消えて件数が減り、自動で解除されると小さいウインドウが消える
- [x] 同じことを LIFO（⌃⌥⌘L）で行うと、⌘V で C、B、A の順に貼られる
- [ ] LIFO の小さいウインドウには「1 C」「2 B」「3 A」と並ぶ
- [x] ⌘V を素早く連打したとき、順番が崩れない
- [x] 次のアプリで 1 件も飛ばずに順番どおりになる: テキストエディット、Ghostty、PhpStorm、Arc（ページの入力欄。例: 検索サイトの検索欄）、Claude デスクトップの入力欄
- [ ] モード中に普通のタイピングが遅くなったり、取りこぼしたりしない

### 小さいウインドウ

- [ ] 件数に合わせて縦に伸びる。12 件積むと、スクロールせずに 1〜12 がすべて見える。10〜12 の 2 桁の番号でも、番号と文字の並びが崩れない
  - 12 件を楽に積む方法: FIFO モードにしてから、Ghostty で次を実行（1 秒ごとに 1 件コピーされる）
  - `for i in $(seq 1 12); do printf "item %02d" $i | pbcopy; sleep 1; done`
- [ ] 画面に収まらない件数では、画面の高さで止まり、中をトラックパッドでスクロールできる（上の `12` を `60` にして試す。13 インチの MacBook Air で 40 件あたりから）
- [ ] テキストエディットで文字を打っている途中に小さいウインドウをクリックし、そのまま続けて文字を打つと、テキストエディットに入る（入力先が移らない）
- [ ] 小さいウインドウをクリックしても、その下にあるもの（デスクトップのアイコンや他のウインドウ）は選ばれない
- [ ] メニューの「見た目 > FIFO / LIFO の小さいウインドウの位置」で、四隅のどこに出すかを変えられる。「…の文字の大きさ」で、文字と小さいウインドウの大きさが変わる

### モード中の履歴ウインドウ

FIFO で A、B、C を積んだ状態から始めてください。

- [ ] ⌃⌘V で開くと、いつもの履歴（「ピン留め」「履歴」の見出し、「すべて / テキスト / …」の絞り込み）が出る。「FIFO 3」のボタンやキューの一覧は出ない
- [ ] 開いている間も、小さいウインドウは出たまま（「残り 3 件」）
- [ ] 操作ボタンが「ペースト ⏎」「書式なし ⇧⏎」「キューに追加 ⌥⏎」になっている（モード外では「コピー ⌥⏎」）
- [ ] 履歴から A、B、C 以外の項目 X を選んで ⏎ を押すと、テキストエディットに X が貼られる。小さいウインドウは「残り 3 件」のまま。続けて ⌘V を押すと A が貼られる（キューは減らず、X もキューに入らない）
- [ ] もう一度開き、項目 Y を選んで ⌥⏎ を押すと、ウインドウは開いたままで、小さいウインドウの最後に Y が追加される（上の確認で A を貼っていれば「残り 2 件」→「残り 3 件」）。続けて別の項目を選んで ⌥⏎ を押すと、さらに追加される
- [ ] 「キューに追加 ⌥⏎」のボタンをクリックしても同じように追加される
- [ ] Esc で閉じてから ⌘V を押していくと、キューの順（B、C、Y …）に貼られ、最後の 1 件のあとにモードが解除される
- [ ] LIFO で同じように ⌥⏎ で Y を追加すると、小さいウインドウの 1 番が Y になり、次の ⌘V で Y が貼られる
- [ ] モード中に検索欄で ⌘V を押すと検索欄に貼られ、キューは減らない
- [ ] A、B、C を積んだ状態で、履歴の B を選んで ⌘⌫ で消すと、小さいウインドウから B が消えて「残り 2 件」になる
- [ ] 履歴ウインドウを開いたまま小さいウインドウをクリックしても、履歴ウインドウは閉じない（検索欄にそのまま文字を打てる）

### 既知の制限
