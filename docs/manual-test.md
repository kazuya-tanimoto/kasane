# 実機での確認項目（MVP）

開発環境ではビルドも動作確認もできていません。Mac で次の順に確認してください。結果は PR かスレッドに書いてもらえれば直します。

## 0. ビルド

- [ ] `make test` が通る
- [ ] `make run` で `build/Kasane.app` ができ、メニューバーにアイコンが出る（Dock には出ない）
- [ ] ビルドでエラーや大量の警告が出たら、ログをそのまま貼ってください

## 1. 権限の案内

- [ ] 初回起動で「Kasane の初期設定」画面が出る
- [ ] 「他のアプリからのペースト」: 「確認を表示」でシステムのダイアログが出て、その後「システム設定 > プライバシーとセキュリティ > 他のアプリからのペースト」に Kasane が出る。「許可」にすると画面の表示が「許可されています」に変わる
  - 「設定を開く」で該当の画面が直接開くか（開かず、プライバシーとセキュリティの一覧が開くだけでも可。どちらだったか教えてください）
- [ ] 「アクセシビリティ」: 「許可する」でシステム設定が開き、許可すると表示が変わる
- [ ] 一度アプリを作り直しても許可が残るか（ad-hoc 署名と `SIGN_IDENTITY="Kasane Dev"` の両方）

## 2. 履歴の取得（最優先）

- [ ] 次をコピーし、それぞれ正しい種類で履歴に出る
  - テキスト: 任意のアプリで文字を選んで ⌘C →「テキスト」
  - URL: Safari のアドレスバーで ⌘C →「URL」、プレビューに URL
  - 画像: ⌃⇧⌘4 で範囲を選ぶ（ファイルに保存せずクリップボードに入れる撮り方）→「画像」
  - ファイル: Finder でファイルを選んで ⌘C →「ファイル」。複数選ぶと 1 件にまとまる
  - リッチテキスト: メモや Pages で太字や色付きの文章を選んで ⌘C →「リッチテキスト」。⏎ で貼ると書式が残る
- [ ] 同じテキストを2回コピーすると1件にまとまり、先頭に移動する
- [ ] 1Password などでパスワードをコピーしたとき、履歴に残らない
- [ ] 待機中の CPU が ほぼ 0%、メモリが 50MB 程度か（アクティビティモニタ）

## 3. 履歴ウインドウと検索

- [ ] ⌃⌘V で画面中央にフェードインで出て、すぐに入力できる
- [ ] 検索欄の周りや操作ボタンの横の空いた所をつかむとウインドウが動く。端をつかむと大きさが変わる
- [ ] 閉じて開き直すと、動かした位置と大きさで出る。別の画面で開いても同じあたりに出る
- [ ] メニューの「見た目 > 履歴ウインドウの位置と大きさを元に戻す」で中央に戻る
- [ ] 角が丸く、角の外にぼかしがはみ出していない
- [ ] 表示までの速さ（体感でもっさりしないか）
- [ ] あいまい検索: `gtps` で `git push` にヒットする
- [ ] ローマ字: `kaigi` で「会議」、`tokyo` と `toukyou` の両方で「東京」にヒットする
- [ ] 人名や固有名詞の読みがどの程度合うか（気づいた例を教えてください）
- [ ] ↑↓ で選択、選択に合わせてリストがスクロールする
- [ ] Esc で検索語が消え、もう一度 Esc で閉じる。ウインドウの外をクリックしても閉じる

## 4. ペースト

- [ ] ⏎ で、ウインドウを開く前に使っていたアプリ（テキストエディット、Slack、ターミナルなど）に貼り付けられる
- [ ] ⇧⏎ で書式なし、⌥⏎ でコピーだけ（貼り付けない）
- [ ] ⌘1〜⌘9 で上から n 番目が貼り付けられる
- [ ] リッチテキストを ⏎ で貼ると書式が残る
- [ ] ⇧⏎ を押したまま貼り付けたとき、⇧⌘V（スタイルを合わせてペースト）にならない
- [ ] 日本語入力（かな入力中）のアプリに貼り付けても問題ない

## 5. FIFO / LIFO（最重要リスク）

要件書で「実機で最優先に検証する」としていた部分です。方式を「⌘V のイベントを貼り付け先に渡す前にクリップボードを入れ替える」に変えたので、その確認をお願いします。

- [ ] ⌃⌥⌘F で FIFO モードになり、メニューバーに「FIFO 0」と出る
- [ ] A、B、C の順にコピーし、メニューバーが「FIFO 3」になる
- [ ] テキストエディットで ⌘V を3回押すと A、B、C の順に貼られ、3回目のあとにモードが自動で解除される
- [ ] 同じことを LIFO（⌃⌥⌘L）で行うと C、B、A の順になる
- [ ] 次のアプリで1件も飛ばずに順番どおりになるか: テキストエディット、ターミナル、VS Code、Slack（Electron）、Safari のフォーム、Excel / Numbers
- [ ] ⌘V を素早く連打したとき、順番が崩れないか
- [ ] モード中に同じショートカットをもう一度押すと解除される
- [ ] モード中に履歴ウインドウを開くと、左のリストがキューに切り替わり、1 番が次に貼り付ける項目になっている
- [ ] ウインドウを開いたままコピーや ⌘V をすると、キューの件数と番号がその場で増減する
- [ ] Tab でキューと履歴の表示を切り替えられる。検索欄に入力すると履歴の表示に戻る
- [ ] 10 件以上積んだとき、番号の札が 2 桁でも崩れない
- [ ] ウインドウを閉じている間、画面の右上にキューの小さな表示が出る。開くと消える。メニューの「見た目」で位置を変えられる
- [ ] 小さな表示がクリックを奪わず、作業の邪魔にならない
- [ ] モード中に普通のタイピングが遅くなったり、取りこぼしたりしないか
- [ ] 既知の制限: メニューの「ペースト」や右クリックからの貼り付けは検知しない

## 6. ピン留め・並び順・削除

- [ ] ⌘P でピン留めすると、リストの上部にまとまる
- [ ] 履歴の保存件数を 100 にすると、ピン留め以外の古いものが消える。ピン留めは残る
- [ ] メニューの「並び順 > 貼り付け回数順」で順番が変わる
- [ ] ⌘⌫ で1件削除、メニューの「履歴を削除」でピン留め以外を全削除

## 7. プレビュー

- [ ] テキスト: 全文と文字数・行数
- [ ] 画像: 画像とサイズ
- [ ] URL: 初期設定ではページを取りに行かず、ドメインと URL だけが出る。メニューの「URL のページ情報を取得」をオンにすると、ページタイトルと代表画像（SNS で共有したときのサムネイル）が出る
- [ ] リッチテキスト: 太字や見出し、色付きの文字が書式付きで出る。ダークモードでも文字が読める
- [ ] PDF ファイル: ページが表示される
- [ ] そのほかのファイル: Quick Look の内容が出る

## 8. 見た目（実機で微調整）

- [ ] モックと比べて、余白、文字の大きさ、色、角の丸みに違和感がないか（気になる点をスクリーンショットで教えてください）
- [ ] メニューの「見た目 > 不透明度」で背景の色の濃さが変わり、ぼかしの強さは変わらない
- [ ] 「見た目 > 背景のぼかし（半径）」で、ぼかしの強さだけが変わり、色の濃さは変わらない。「なし」でぼかしが消える
- [ ] 「見た目 > 小さな表示の文字の大きさ」で、FIFO / LIFO 中の小さな表示の文字と大きさが変わる
- [ ] ライトモードとダークモードの両方で読みやすいか
- [ ] ⌘I でプレビューの下に詳細が出て、もう一度押すと消える。次に開いたときも状態が残る
