## 5. FIFO / LIFO（最重要リスク）

要件書で「実機で最優先に検証する」としていた部分です。方式は「⌘V のイベントを貼り付け先に渡す前に、クリップボードを入れ替える」です。

FIFO / LIFO は、ショートカット（⌥⌘F / ⌥⌘L）か、メニューバーのメニューの「FIFO モードを開始」「LIFO モードを開始」で始めます。履歴ウインドウにはボタンがありません。

以下の A、B、C は、テキストエディットに「A」「B」「C」と 1 行ずつ書いておき、1 行ずつ選んで ⌘C でコピーしてください。

### 基本

- [x] ⌥⌘F で FIFO モードになり、メニューバーに「FIFO 0」と出る
- [x] 始めると同時に画面の右上に小さいウインドウが出て、「FIFO」の札、「残り 0 件」「コピーするとここに追加されます」と出る
- [x] モード中に同じショートカットをもう一度押すと解除される
- [x] 解除すると小さいウインドウが消える
- [x] メニューバーのメニューの「FIFO モードを開始」でも同じように始まる
- [x] A、B、C の順にコピーすると、メニューバーが「FIFO 3」になる
- [x] そのとき小さいウインドウに「1 A」「2 B」「3 C」と並ぶ。1 の番号はアクセントカラーの色で、A は太字
- [x] テキストエディットで ⌘V を 3 回押すと A、B、C の順に貼られ、3 回目のあとにモードが自動で解除される
- [x] ⌘V を押すたびに小さいウインドウの一番上が消えて件数が減り、自動で解除されると小さいウインドウが消える
- [x] 同じことを LIFO（⌥⌘L）で行うと、⌘V で C、B、A の順に貼られる
- [x] LIFO の小さいウインドウには「1 C」「2 B」「3 A」と並ぶ
- [x] ⌘V を素早く連打したとき、順番が崩れない
- [x] 次のアプリで 1 件も飛ばずに順番どおりになる: テキストエディット、Ghostty、PhpStorm、Arc（ページの入力欄。例: 検索サイトの検索欄）、Claude デスクトップの入力欄
- [x] モード中に普通のタイピングが遅くなったり、取りこぼしたりしない

### 小さいウインドウ

- [x] 件数に合わせて縦に伸びる。12 件積むと、スクロールせずに 1〜12 がすべて見える。10〜12 の 2 桁の番号でも、番号と文字の並びが崩れない
  - 12 件を楽に積む方法: FIFO モードにしてから、Ghostty で次を実行（1 秒ごとに 1 件コピーされる）
  - `for i in $(seq 1 12); do printf "item %02d" $i | pbcopy; sleep 1; done`
  - fishの場合：`for i in (seq 1 75); printf "item %02d" $i | pbcopy; sleep 1; end`
- [x] 画面に収まらない件数では、画面の高さで止まり、中をトラックパッドでスクロールできる（上の `12` を `60` にして試す。13 インチの MacBook Air で 40 件あたりから）
- [x] テキストエディットで文字を打っている途中に小さいウインドウをクリックし、そのまま続けて文字を打つと、テキストエディットに入る（入力先が移らない）
- [x] 小さいウインドウをクリックしても、その下にあるもの（デスクトップのアイコンや他のウインドウ）は選ばれない
- [x] メニューの「見た目 > FIFO / LIFO の小さいウインドウの位置」で、四隅のどこに出すかを変えられる。「…の文字の大きさ」で、文字と小さいウインドウの大きさが変わる
- [x] 小さいウインドウが出ている間にぼかしを なし → 10 にしても、角が丸いまま（2026-10-19 確認済み）

### モード中の履歴ウインドウ

A
B
C

FIFO で A、B、C を積んだ状態から始めてください。

- [x] ⌥V で開くと、モード外と同じ履歴のリストと「すべて / テキスト / …」の絞り込みが出る。前の版にあった「FIFO 3」のボタンや、キューだけの一覧は出ない
- [x] 開いている間も、小さいウインドウは出たまま（「残り 3 件」）
- [ ] 操作ボタンが「ペースト ⏎」「書式なし ⇧⏎」「キューに追加 ⌘⏎」になっている（モード外では「コピー ⌘⏎」）
- [ ] 履歴から A、B、C 以外の項目 X を選んで ⏎ を押すと、テキストエディットに X が貼られる。このとき小さいウインドウは「残り 3 件」のまま（履歴ウインドウからの貼り付けはキューを使わない。X もキューに入らない）
- [ ] 続けてテキストエディットで ⌘V を押すと、X ではなく A が貼られ、小さいウインドウが「残り 2 件」に減る（ここからはふつうの FIFO の ⌘V）
- [ ] もう一度開き、項目 Y を選んで ⌘⏎ を押すと、ウインドウは開いたままで、小さいウインドウの最後に Y が追加される（上の確認で A を貼っていれば「残り 2 件」→「残り 3 件」）。続けて別の項目を選んで ⌘⏎ を押すと、さらに追加される
- [ ] 「キューに追加 ⌘⏎」のボタンをクリックしても同じように追加される
- [x] Esc で閉じてから ⌘V を押していくと、キューの順（B、C、Y …）に貼られ、最後の 1 件のあとにモードが解除される
- [ ] LIFO で同じように ⌘⏎ で Y を追加すると、小さいウインドウの 1 番が Y になり、次の ⌘V で Y が貼られる
- [ ] モード中に ⌥V で開き、検索欄で ⌘V を押すと、検索欄に文字が入り、小さいウインドウの件数は変わらない（検索欄への ⌘V はキューを使わない）
- [ ] 履歴から消してもキューは変わらない: A、B、C を積み直した状態（小さいウインドウが「残り 3 件」）で ⌥V で開き、検索欄に `B` と打って履歴の「B」を選び、⌘⌫（⌘ を押しながら delete キー）を押す。履歴から B は消えるが、小さいウインドウは「1 A」「2 B」「3 C」「残り 3 件」のまま。Esc で閉じてテキストエディットで ⌘V を 3 回押すと、A、B、C の順に貼られる
  - A、B、C の積み直し方: いったん ⌥⌘F で解除し、もう一度 ⌥⌘F で始めてから、A、B、C を順に ⌘C でコピーする
- [x] 履歴ウインドウを開いたまま小さいウインドウをクリックしても、履歴ウインドウは閉じない（検索欄にそのまま文字を打てる）

## 6. ピン留め・並び順・削除
