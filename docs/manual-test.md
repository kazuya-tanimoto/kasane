## 5. FIFO / LIFO（最重要リスク）

要件書で「実機で最優先に検証する」としていた部分です。方式は「⌘V のイベントを貼り付け先に渡す前に、クリップボードを入れ替える」です。

FIFO / LIFO は、ショートカット（⌥⌘F / ⌥⌘L）か、メニューバーのメニューの「FIFO モードを開始」「LIFO モードを開始」で始めます。履歴ウインドウにはボタンがありません。

以下の A、B、C は、テキストエディットに「A」「B」「C」と 1 行ずつ書いておき、1 行ずつ選んで ⌘C でコピーしてください。

### 基本

- [x] ⌥⌘F で FIFO モードになり、メニューバーに「FIFO 0」と出る
- [x] 始めると同時に画面の右上に小さいウインドウが出て、「FIFO」の札、「残り 0 件」「コピーするとここに追加されます」と出る
- [x] モード中に同じショートカットをもう一度押すと解除される
- [x] 解除すると小さいウインドウが消える
- [x] メニューバーのメニューの「FIFO モードを開始」でも同じように始まる
- [x] A、B、C の順にコピーすると、メニューバーが「FIFO 3」になる
- [x] そのとき小さいウインドウに「1 A」「2 B」「3 C」と並ぶ。1 の番号はアクセントカラーの色で、A は太字
- [x] テキストエディットで ⌘V を 3 回押すと A、B、C の順に貼られ、3 回目のあとにモードが自動で解除される
- [x] ⌘V を押すたびに小さいウインドウの一番上が消えて件数が減り、自動で解除されると小さいウインドウが消える
- [x] 同じことを LIFO（⌥⌘L）で行うと、⌘V で C、B、A の順に貼られる

### 履歴

- [ ] 「並び順」で「ペースト回数順」を選ぶ → ⌥V で開くと、ペーストした回数の多い順に並ぶ。「コピー日時順」に戻す
- [ ] 「履歴の保存件数」を今の件数より少なくして（例: 今 1,000 件なら 100 件）、ピン留め以外の件数がそれより多いとき → 設定ウインドウの上に「古い履歴 n 件を削除しますか？」の確認が出て、右の「削除」が赤い
- [ ] その確認で ⏎ を押す → 何も起きない（どちらのボタンも ⏎ では押されない）
- [ ] Esc を押す → 確認が閉じ、件数は前のまま
- [ ] もう一度選んで「削除」を押す → 件数が変わり、⌥V で開くと古い項目が消えていて、ピン留めは残っている。試したあとは件数を元に戻す
- [ ] 件数を増やすとき（例: 100 件から 1,000 件）は、確認が出ない
- [ ] 「履歴に残さないアプリ」で ＋ を押す → 「開いているアプリ」の一覧に、今開いているアプリが名前順に出て、Kasane は出ない
- [ ] そこでメモを選ぶ → 一覧にメモのアイコンと名前が出る。ポインタを重ねると「com.apple.Notes」と出る
- [ ] メモで文をコピーする → ⌥V で開いても、その文は履歴にない
- [ ] 一覧のメモを選んで − を押す → 一覧から消える。メモで文をコピーすると、履歴に残る
- [ ] ＋ の「ほかのアプリを選ぶ…」→ アプリケーションのフォルダが開き、アプリを選んで「追加」を押すと一覧に出る（試したあとは − で外す）
- [ ] 「履歴を削除…」の文字が赤い
- [ ] 「履歴を削除…」を押す → 設定ウインドウの上に確認が出て、右の「削除」ボタンは赤くない（Mac の設定のアクセントカラー。ふつうは青）
- [ ] その確認で Esc を押す → 確認が閉じ、⌥V で開くと何も消えていない

### ショートカット

- [ ] 3 行に「⌥V」「⌥⌘F」「⌥⌘L」が出ていて、右に戻すボタンは出ていない
- [ ] 「履歴ウインドウを開く / 閉じる」の欄をクリック → 「キーを押してください」になる。そのまま ⌥V を押す → 履歴ウインドウは開かず、欄が「⌥V」に戻る
- [ ] 欄をクリックして ⇧⌘V を押す → 「⇧⌘V」になり、右に戻すボタンが出る。メニューバーのメニューも「履歴を開く ⇧⌘V」になる
- [ ] 設定ウインドウを閉じて ⇧⌘V を押す → 履歴ウインドウが開く。⌥V では開かない
- [ ] 戻すボタンにポインタを重ねる → 「標準のキー（⌥V）に戻す」と出る。押す → 「⌥V」に戻り、ボタンが消える
- [ ] 欄をクリックして V だけを押す → 赤い文字で「⌘ ⌥ ⌃ のどれかを含めてください」と出て、キーは「⌥V」のまま
- [ ] 欄をクリックして ⌥⌘F を押す → 「⌥⌘F は「FIFO モードの開始 / 終了」に使っています。⌥V のままです」と出る
- [ ] 履歴の欄を ⇧⌘V にしておく。Ghostty で `cd ~/src/kasane && swift scripts/hold-hotkey.swift` を流し、「⌥V を押さえました」と出たら、設定に戻って戻すボタン（標準のキー（⌥V）に戻す）を押す → 赤い文字で「⌥V はほかのアプリが使っています。⇧⌘V のままです」と出て、キーは ⇧⌘V のまま
- [ ] Ghostty で ⌃C を押してスクリプトを止め、もう一度戻すボタンを押す → 「⌥V」に戻り、赤い文字が消える
- [ ] 欄をクリックしてから Esc → 待ちが終わり、キーは変わらない。もう一度クリックしてから欄の外をクリック → 同じく待ちが終わる
- [ ] 待ちが終わったあとで ⌥V を押す → 履歴ウインドウが開く（外したキーが戻っている）
- [ ] 欄をクリックして待っている間に、同じ欄をもう一度クリック → 待ちが終わる（もう一度待ちにはならない）
- [ ] 欄をクリックして待っている間に ⌘Tab でメモに移る → 待ちが終わる。そのまま ⌥V を押す → 履歴ウインドウが開く
- [ ] 欄をクリックして待っている間に ⌘W を押す → 「⌘W はどのアプリでも使うキーです。⌥V のままです」と出て、設定ウインドウは閉じない
