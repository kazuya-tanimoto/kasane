## 仕様どおりの制限（不具合ではない）

- 履歴ウインドウには、FIFO / LIFO を始める・終えるボタンも、モードの表示もない
  - 始め方と終え方は、ショートカットか、メニューバーのメニューだけです。
  - モード中かどうかは、メニューバーのアイコンと小さいウインドウで見ます。
- 小さいウインドウは動かせない。位置は設定の「外観」で左 / 右から選ぶ（2026-10-30 から、画面の左端か右端に上下いっぱいの帯で出る。幅だけ、帯の内側の端のドラッグで変えられる）
- FIFO / LIFO 中に、メニューの「ペースト」や右クリックから貼り付けると、キューは次に進まない
  - Kasane は ⌘V を押したときだけ、クリップボードをキューの次の項目に替えるためです。
  - そのときは、クリップボードに今ある内容がそのまま貼られます。
- PR #2 より前に保存した履歴は、同じものをもう一度コピーすると、1 回だけ別の項目として入る
  - 重複をまとめる計算を変えたためです。新しくコピーしたものは正しくまとまります。

## 5. FIFO / LIFO（最重要リスク）

要件書で「実機で最優先に検証する」としていた部分です。方式は「⌘V のイベントを貼り付け先に渡す前に、クリップボードを入れ替える」です。

FIFO / LIFO は、ショートカット（⌥⌘F / ⌥⌘L）か、メニューバーのメニューの「FIFO モードを開始」「LIFO モードを開始」で始めます。履歴ウインドウにはボタンがありません。

以下の A、B、C は、テキストエディットに「A」「B」「C」と 1 行ずつ書いておき、1 行ずつ選んで ⌘C でコピーしてください。

## 14. URL のタイトルと画像の先読み（2026-10-30 追加、2026-10-31 書き直し）

   - この版から初期値はオンです。

   - この章では、URL をターミナルのコマンドでコピーします。
3. 別のターミナルのウインドウで、下の「ログを見るコマンド」を流し、そのままにする
   - 取りに行った URL が、ここに出ます。
   - 止めるときは ⌃C です。
   - この章では、このウインドウを「ログのウインドウ」と呼びます。

ログを見るコマンド:

```
log stream --level info --predicate 'subsystem == "io.github.kazuya-tanimoto.kasane" AND category == "link"'
```

ログを消してから見るコマンド（前の手順のログと分けるため、各手順の最初に使います）:

```
clear; log stream --level info --predicate 'subsystem == "io.github.kazuya-tanimoto.kasane" AND category == "link"'
```

ログの読み方:

- `fetch 番号 ホスト名`: 取りに行った
- `saved 番号`: 取れて保存した
- `skip 番号 (offline)`: オフラインなので、取りに行かなかった
- `skip 番号 (fetched recently)`: 1 日以内に取りに行った URL なので、取りに行かなかった
- 番号は、履歴の項目の番号です。
- 同じ番号の `fetch` と `saved` は、同じ行のものです。
- ほかの行（`show`、`hide`、`visible`、`select`、`request`）は見なくてよいです。

この章の URL は、どれもコマンドでコピーし、末尾に今の時刻を付けて毎回新しい URL にしています。
一度取りに行った URL は 1 日たつまで取り直さないので、同じ URL ではテストにならないためです。

## 20. 履歴ウインドウの角・縁・影（2026-10-31 追加）

履歴ウインドウの角・縁・影を、デザインモックの値にしました。
仕組みを作り直したので、見た目に加えて、端と角で大きさを変えられることと、開き直したときの位置と大きさも見ます。

準備（1〜2 の順に）:

- [ ] 履歴ウインドウの下側に、下へ広がる薄い影が見える（上側にはほとんど影がない）

- [ ] 履歴ウインドウの右下の角をつかんで斜めにドラッグする → カーソルが斜めの矢印になり、幅と高さが一緒に変わる
